# PDF Viewer

**Python**、**PyQt5**、**PyMuPDF** を使用して作成したシンプルな PDF ビューワです。

PDFファイルの表示、キーワード検索、ページジャンプ、ドラッグ＆ドロップによるファイルオープン、階層付き目次（TOC）からのページ移動など、一般的によく利用する機能を備えています。

> Python と PyQt5 を用いたデスクトップ向け PDF ビューワの学習・実装例として作成しました。

---

## 主な機能

- PDFファイルを開く
- ドラッグ＆ドロップによるPDFオープン
- 階層付き目次（TOC）の表示
- 目次クリックによるページジャンプ
- キーワード検索（`Ctrl + F`）
- 指定ページへのジャンプ
- ツールバー・メニューバー
- PDFの保存
- PDFの印刷

---

## 動作環境

- Python 3.9 以降
- Windows 10 / Windows 11
- PyQt5
- PyMuPDF

主に Windows 環境で動作確認を行っていますが、Linux や macOS でも動作する可能性があります。

---

## 環境構築

まず、本リポジトリを取得します。

```bash
git clone https://github.com/QPointPlace/pdf_viewer.git
cd pdf_viewer
```

仮想環境の作成（推奨）

```bash
python -m venv venv
```

仮想環境を有効化します。

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

必要なライブラリをインストールします。

```bash
pip install PyQt5 PyMuPDF
```

---

## 実行方法

以下のコマンドで起動します。

```bash
python pdf_viewer.py
```

起動後は次の操作が可能です。

- **ファイル → 開く** からPDFを開く
- PDFファイルをドラッグ＆ドロップして開く
- **Ctrl + F** でキーワード検索
- ページ番号を入力してジャンプ
- 左側の目次をクリックして該当ページへ移動

---

## 実行結果

アプリケーションを起動すると、次のような機能を利用できます。

- PDFファイルを表示
- PDFにしおり（アウトライン）がある場合は、階層付き目次をツリー表示
- 目次をクリックすると該当ページへジャンプ
- キーワード検索を実行すると、最初に一致したページへ移動
- ドラッグ＆ドロップによるPDFオープン
- ページ番号入力によるページジャンプ
